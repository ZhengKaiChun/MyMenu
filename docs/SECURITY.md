# 安全边界与验证

## 已实施

- 公开菜品与私有做法分表、分接口。吃饭方请求做法直接403；跨家庭资源返回404。
- 家庭角色从数据库成员关系读取，不接受客户端自报role授权。
- 全部外部参数经过Zod严格校验；用户值使用参数化SQL；排序表名仅在固定枚举中选择。
- 不使用客户端数据库或浏览器状态当真实业务结果。服务端事务、家庭行锁、唯一约束和版本号保护关键状态。
- 一次性邀请token与分享token用256位随机数，数据库仅存SHA256；七天过期、可撤销，解散后失效。
- 登录使用随机会话、哈希存储和到期时间；注销/退出可撤销。密码使用独立盐的scrypt，微信AppSecret不下发。
- 手机号AES-256-GCM加密；索引与验证码均HMAC，验证码5分钟、五次尝试、一次性、60秒重发、每日额度。
- 上传限制大小与像素，拒绝SVG等可执行格式，重编码为WebP并清除元数据；读取使用短期签名链接，禁止任意路径读取。
- 全局及身份接口限流，固定上游服务域名、网络超时、错误脱敏与请求ID；日志不记录密码、Authorization或带令牌的请求URL。
- 导入覆盖有预览和版本核验，整本替换软归档，已点餐次和其他家庭成员的来源不被删除。
- 解散须所有有效成员投票；成员变动使旧申请失效，拒绝/撤回不解散。
- 版本化迁移内容校验、本地数据库单进程锁、生产配置启动检查、非root容器、数据库端口不对公网开放。

## 仍需部署和运营保障

- 生产使用独立PostgreSQL、独立数据库用户与最小权限。通过私网和防火墙限制来源，远程连接启用证书验证。
- 服务器补丁、密钥轮换、域名与证书、WAF/异常监控、短信预算和外部依赖持续更新。
- 定期备份数据库和图片，并实际演练恢复；备份不得上传到代码仓库。
- 图片签名链接是短期Bearer URL，持有者在有效期内可查看；不要发到公开日志。
- 当前测试不等于第三方渗透测试，也不保证不存在未知漏洞。上线前需真机、业务权限和基础设施复核。

## 检查命令

`npm.cmd run lint`、`npm.cmd run check`、`npm.cmd test`、`npm.cmd audit --omit=dev`。

测试覆盖越权、SQL形状输入、私有做法剔除、令牌撤销、多人点同菜换菜、分享独立性、全员投票、短信尝试限制和原生页面事件连接。微信实际授权/短信真实发送需配置服务后联调，不能把测试替身当作供应商验收。
