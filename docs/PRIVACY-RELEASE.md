运营者：郑恺纯；个人信息保护联系邮箱：2834389993@qq.com。

应用内全文见 miniprogram/features/legal.js，首页与登录页均可查看。发布前须在微信后台“设置 → 服务内容声明 → 用户隐私保护指引”填写相同主体、邮箱、实际接口与处理目的；真实审核与主体信息公示需由运营者完成，本地文案不能替代微信后台配置或审核。

仅按实际启用能力申报：微信登录标识、用户主动填写的昵称头像、主动选择的图片、可选手机号及通知订阅。没有定位、通讯录、支付、广告追踪或AI优化接口。短信服务尚未配置时不宣称发送短信；若新增短信或托管服务商，需补充受托方与实际部署信息后再启用。

正式数据库部署在中国境内，确认托管服务协议和最小访问权限，检查日志不含登录令牌、完整手机号或上传图片内容。注销已撤销账号会话、直接标识、个人食材及通知，家庭共同记录去标识化保留至业务期限。家庭做法只向饲养员及主动分享的收件人开放。
