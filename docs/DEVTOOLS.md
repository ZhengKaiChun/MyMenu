# 微信开发者工具导入

1. 启动独立后端：在项目根目录运行 `npm.cmd run dev`，终端显示 API 地址 `http://127.0.0.1:3000`。
2. 打开微信开发者工具 → 导入项目。目录选择整个 `menu` 根目录，不是单独 miniprogram 子目录。
3. AppID：`wx3ab03337b159fadd`；项目类型为小程序，后端服务选择“不使用云服务”。本项目使用独立后端与数据库。
4. 仅本地联调时：详情 → 本地设置 → 临时关闭合法域名/HTTPS证书校验。不要改正式 project.config.json 的 urlCheck=true。
5. 点编译。先用账号注册，登录后默认为野生小猪，直接创建或加入小家。也可以先运行 `npm.cmd run dev:seed`，从 `.runtime/demo-accounts.json` 读取本机随机测试密码，分别登录做饭和吃饭账户。
6. 添加菜品：小家 → 菜谱与合集管理 → 添加菜品，填写用料和步骤并保存；图片会上传到独立服务端。
7. 双角色联调：分别登录两位测试账户，吃饭方点菜；做饭方在开饭回音中答应/拒绝或处理换菜。

## 真机预览

手机访问不了电脑自己的127.0.0.1。真机使用已部署的HTTPS后端，或你控制的可访问测试域名；不要关闭正式证书校验。不要把数据库端口暴露给手机。

## 微信登录、手机号与隐私

复制 `.env.example` 为 `.env`，在服务端配置 WECHAT_SECRET；密钥仅存服务器，不进 Git、不进小程序。微信手机号接口还需对应主体具备资格，并配置 PHONE_ENCRYPTION_KEY（32字节十六进制）。短信使用独立短信服务配置，不是微信原生短信API。服务未配置时入口隐藏或明确提示不可用。

在小程序后台配置与实际数据用途相符的用户隐私保护指引；头像和图片由用户主动选择，授权弹窗使用微信原生隐私接口。正式文案需要运营者确认。

## 上传

先部署独立后端并在微信后台登记 request/uploadFile/downloadFile 的HTTPS合法域名，再运行：

```powershell
node scripts/configure.mjs production https://你的后端域名
npm.cmd run check
```

完成生产配置后，在微信开发者工具中点“上传”，填写版本号和说明。也可在已登录并开启工具服务端口后使用 `npm.cmd run upload -- 0.1.0`。没有生产域名时，脚本会阻止上传，避免把开发地址带入正式包。
