# 直接导入微信开发者工具

1. 打开微信开发者工具，选择“导入项目”。
2. 目录选 D:\codex\projects\给我饭\menu（整个根目录，不是miniprogram子目录）。
3. AppID已经填写为wx3ab03337b159fadd；使用本项目独立后端，不需要选择微信云开发环境。
4. 点击“编译”。登录页勾选协议，点“直接体验小厨房”，即可进入小家选择页面。

默认已经启用“本机体验”，无需启动start-local.cmd，无需配置域名，也无需关闭合法域名校验。原生页面和示例菜图均在包内，后台服务关闭也能预览。若之前已导入这个路径，直接重新编译即可。

## 如何体验

体验小家“两只小猪的家”有4道菜，包含两位成员。进入小家后可点餐、查看全家今日菜单、准备食材、编辑菜谱和分享菜谱。创建小家就是饲养员，另一账号通过邀请加入可成为大懒猪；点菜回音和解散确认需要切换到另一身份继续操作。

注册一个新的本机测试账号后，默认为野生小猪，直接进入创建/加入小家页面；新建小家没有强制资料、食材或菜品录入。请使用测试密码，本机体验不是正式账号。

体验数据仅在当前设备保存，不会写入独立服务器数据库，也不在不同手机间同步。邀请和分享数据仍属当前设备；跨设备邀请、分享、真实微信登录、短信、订阅提醒要接入正式后台后才生效，不能把体验结果当作供应商联调。

## 手机扫码预览

在微信工具中点击“预览”生成二维码，使用有开发权限的微信扫码。当前本机体验不依赖电脑的127.0.0.1，所以手机不需要连接电脑后台。微信工具和账号本身仍须联网且有对应AppID权限。

## 切换到真实后台

需要真实账号和多设备同步时，先按README启动或部署独立后台，再执行：

```powershell
node scripts/configure.mjs development http://127.0.0.1:3000
```

仅此本机联网调试方式需要在“详情 → 本地设置”临时关闭域名与HTTPS校验。手机访问不了电脑的127.0.0.1，手机使用可访问的HTTPS测试后台。

恢复开箱即用体验：`node scripts/configure.mjs preview`。

## 正式上传

先部署HTTPS后台，配置服务端.env中的微信AppSecret和真实服务，再在微信后台登记request/uploadFile/downloadFile合法域名与隐私用途。之后运行：

```powershell
node scripts/configure.mjs production https://你的后端域名
npm.cmd run check
npm.cmd run upload -- 0.2.0
```

也可在完成生产配置后从微信工具上传。上传脚本会拒绝体验模式与开发地址；正式发布环境也禁止体验存储，避免把本机示例数据当成线上数据。上传不等于通过微信审核。
